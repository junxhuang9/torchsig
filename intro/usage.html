Usage

如何开始使用 TorchSig？

可以直接用 Python API 在线生成样本，也可以通过 YAML 配置批量生成离线数据集。

1. 安装开发版

git clone https://github.com/TorchDSP/torchsig.git
cd torchsig
pip install -e .

2. 在线生成一个小型分类数据流

from torchsig.datasets.datasets import TorchSigIterableDataset
from torchsig.transforms.transforms import ComplexTo2D
from torchsig.utils.defaults import TorchSigDefaults
from torchsig.utils.data_loading import WorkerSeedingDataLoader

metadata = TorchSigDefaults().default_dataset_metadata
metadata.update({
    "num_iq_samples_dataset": 4096,
    "fft_size": 64,
    "fft_stride": 64,
    "num_signals_min": 1,
    "num_signals_max": 1,
})

dataset = TorchSigIterableDataset(
    signal_generators=["bpsk", "qpsk", "16qam"],
    metadata=metadata,
    transforms=[ComplexTo2D()],
    target_labels=["class_index"],
    seed=123,
)

loader = WorkerSeedingDataLoader(dataset, seed=123, batch_size=8, num_workers=0)
inputs, labels = next(iter(loader))

3. 通过 YAML 生成离线数据集

python scripts/generate_dataset_from_config.py \
  --root ./data \
  --config torchsig/datasets/default_configs/narrowband_toy_dataset.yaml \
  --overwrite \
  --batch_size 32 \
  --num_workers 0 \
  --save_config_copy
YAML 的关键字段包括 dataset_length、seed、impairment_level、output.representation、signal_sampling.mode 和 dataset_metadata。

4. 加载已生成数据集

from torchsig.datasets.datasets import StaticTorchSigDataset

static_dataset = StaticTorchSigDataset(
    root="./data/narrowband_toy_dataset",
    target_labels=["class_index"],
)

sample, target = static_dataset[0]

5. 选型建议

我要训练分类器

设置 num_signals_max=1，使用 ComplexTo2D 或原始 I/Q，标签选择 class_index。

我要训练检测器

设置 num_signals_max>1，使用 Spectrogram 和 YOLOLabel。

我要复现实验

固定 YAML、seed 和输出目录，使用 DatasetCreator 生成静态 HDF5 数据集。
