Signal Processing + PyTorch

用一组静态 HTML 快速理解 TorchSig

TorchSig 是面向信号处理机器学习的数据工具库，围绕 PyTorch 数据管线提供合成信号生成、射频损伤仿真、数据增强、检测/分类标签构建，以及离线数据集写入与加载能力。

这组页面包含什么？

能力地图

总结 TorchSig 能生成哪些信号、支持哪些任务、有哪些 transform 和数据输出形式。

代码组成

按 datasets、signals、transforms、utils 和脚本目录解释仓库模块职责。

工作原理

把动态样本生成过程拆成噪声底、信号生成、损伤应用、频移放置、标签提取和写盘加载。

使用方式

给出内存数据集、YAML 配置、静态数据集和 Lightning DataModule 的最小用法。

最适合的使用场景

1
调制识别

生成单信号窄带样本，训练分类器识别 BPSK、QAM、OFDM、AM/FM 等类别。

N
宽带检测

在一个观测窗口内放置多个信号，输出频谱图和检测标签。

RF
损伤仿真

模拟噪声、漂移、相位噪声、IQ 不平衡、衰落、功放非线性和干扰。
