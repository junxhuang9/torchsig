Architecture

TorchSig 由哪些模块组成？

项目结构围绕数据集、信号对象、信号生成器、transform、文件读写和默认配置展开。

模块职责

模块关键对象作用
torchsig/datasetsTorchSigIterableDataset, StaticTorchSigDataset, TorchSigDataModule动态生成样本、加载静态数据集、适配 Lightning 训练。
torchsig/signalsSignal, SignalMetadataObject, BaseSignalGenerator描述信号数据和元数据，提供各调制类别的生成器。
torchsig/transformsTransform, Compose, Impairments, Spectrogram, YOLOLabel实现损伤、增强、表示转换和检测标签转换。
torchsig/utilsDatasetCreator, WorkerSeedingDataLoader, TorchSigDefaults提供写盘、可复现加载、默认元数据和 DSP 工具。
scriptsgenerate_dataset_from_config.py从 YAML 配置生成可复用的离线数据集。
examplesnotebooks演示分类、检测、数据创建、文件处理和 transform 可视化。

对象关系

YAML / metadata
定义采样率、样本长度、信号数量、SNR、带宽和输出表示。
Signal generators
按类别或调制族生成 component signal。
Transforms
对 component 或完整样本应用损伤、增强和格式转换。
TorchSigIterableDataset
生成无限流式样本，可直接接 DataLoader。
DatasetCreator
把动态样本写成静态数据集。
StaticTorchSigDataset
从磁盘随机访问已生成样本。
